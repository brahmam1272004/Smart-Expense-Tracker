# Expense Tracker

## Project Topic
Flutter-Based Personal Expense Tracker Application

## Description
Expense Tracker is a mobile application developed using Flutter that helps users manage their daily income and expenses. Users can add, view, edit, and delete transactions, track their spending, and view category-wise expense summaries.

## Features
- Add income and expenses.
- Select transaction categories and dates.
- View transaction history.
- View detailed transaction information.
- Edit and delete transactions.
- View total income and expenses.
- View category-wise spending reports.
- Save transaction data locally using SharedPreferences.

## Technologies Used
- Flutter
- Dart
- Provider (State Management)
- SharedPreferences (Local Storage)

## Project Structure
- `lib/models` – Data models
- `lib/services` – Provider and data management
- `lib/screens` – Application screens
- `lib/widgets` – Reusable UI components

## How to Run
1. Install Flutter SDK.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run `flutter pub get`.
5. Run `flutter run`.

## APK
The release APK is available in the `apk` folder as `app-release.apk`.
